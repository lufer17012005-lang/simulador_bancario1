BASE DE DATOS SIMULADA — BANCO DATA
====================================

El archivo bancodata-respaldo-demo.json contiene ocho cuentas, movimientos recientes, turnos FIFO y solicitudes prioritarias de demostración. Todos los nombres, documentos, teléfonos, saldos y correos son ficticios.

Para cargar los datos en la página:
1. Abre el simulador publicado.
2. En Resumen, pulsa “Cargar respaldo”.
3. Selecciona bancodata-respaldo-demo.json (descárgalo desde este repositorio si no lo tienes localmente).
4. La aplicación importará y guardará los registros en IndexedDB de ese navegador. Al recargar la página, los datos permanecerán.

Importar el respaldo reemplaza el conjunto de datos actual en ese navegador. Si quieres conservar tus datos actuales, pulsa primero “Exportar respaldo” y guarda una copia.

Para simulación académica únicamente. No introduzcas datos personales o financieros reales.
